# 집중의 숲 — Stitch 최종 7화면 디자인

생성 및 다운로드: 2026-10-17, Google Stitch 웹 UI (로그인된 Chrome).
프로젝트: https://stitch.withgoogle.com/projects/6960462687788289405?pli=1

## 파일 안내

| 폴더 | 화면 |
|---|---|
| 01 | 홈 — 혼자 하기, 방 만들기, 코드 참여 |
| 02 | 시간 설정 — 1분 체험, 10/25/50분 |
| 03 | 함께 대기방 — 초대코드 및 준비 |
| 04 | 집중 준비 — 소리와 화면 켜짐 유지 |
| 05 | 집중 중 — 공동 나무, 타이머, 친구 상태 |
| 06 | 이탈 일시정지 — 복귀 대기 및 도전 종료 |
| 07 | 완료와 보상 — 공동 완주와 보너스 |

각 폴더의 `code.html`은 Stitch에서 내보낸 HTML이고 `screen.png`는 해당 화면 이미지입니다.
`DESIGN.md`는 Stitch가 내보낸 디자인 시스템입니다.

## 열기

`index.html`을 열면 7개 화면 이미지와 HTML 링크를 볼 수 있습니다.
HTML에는 외부 폰트/CDN/이미지 링크가 포함되어 있어 인터넷 연결이 필요할 수 있습니다.
PNG는 화면 형태를 확인하는 고정 이미지입니다.

## 확인된 범위

- 참고 콘셉트 이미지를 Stitch에 실제 첨부해 생성
- 7개 화면의 HTML과 PNG, 디자인 시스템 파일 다운로드 확인
- 원본 HTML/PNG는 수정하지 않고 보존
- 초안 4화면은 별도 전체 내보내기 ZIP에 보존

이 파일은 디자인 및 화면별 데모입니다. 초대코드와 참여자 상태는 시안 데이터이며 실시간 공동방 서버가 아닙니다. 일부 버튼이나 타이머가 화면에서 반응하더라도 멀티플레이, 이탈 동기화, 음악 재생, 실제 화면 켜짐 유지 동작을 검증한 완성 앱이 아닙니다.

후속 구현 시 영문 공통 헤더를 한국어로 정리하고 화면 켜짐 상태 문구를 실제 상태에 맞게 연결해야 합니다. 3명 1.5배 보상은 화면에 있으나, 합의한 2명 1.2배 안내는 추가 반영해야 합니다.

소스 확인상 `visibilitychange`, 실제 Wake Lock, 오디오 재생, 실시간 통신 및 기록 저장은 구현되지 않았습니다. 타이머는 화면 내 시뮬레이션입니다.
